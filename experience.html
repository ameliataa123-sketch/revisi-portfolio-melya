My Experience icreate a website

I have experience creating simple websites using HTML, CSS, Bootstrap, and basic JavaScript. I started learning web development because I was interested in technology and website design. Making websites helps me improve my creativity and coding skills.

One of the websites I created is a personal portfolio website. In this project, I added information about myself, my skills, and some projects I have made. I also learned how to arrange layouts and choose suitable colors to make the website more attractive.

I have also created a shoe store landing page website. In this project, I used Bootstrap to make the website responsive and easier to use on different devices. I added navigation menus, dropdown features, product images, and promotional sections.

Besides that, I designed a pet care website with a simple and modern appearance. I practiced adding animations, buttons, and images to make the website look more interactive. This project helped me understand how to create user-friendly website designs.

Through these experiences, I learned many important things about website development. I became more familiar with coding, website structure, and responsive design. I hope to continue improving my skills and create even better websites in the future.
