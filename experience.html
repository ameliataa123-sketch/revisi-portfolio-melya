My Experience in Learning Coding

Learning how to code has been one of the most challenging yet rewarding experiences I have ever had. Last month, I decided to create my own project to improve my skills. I was very excited at first, but I did not know that the process would be so difficult.

At the beginning, everything seemed okay. I wrote the codes step by step. However, when I tried to run the program, it did not work. There were so many error messages that appeared on the screen. I felt really confused and frustrated.

There were times when I felt so tired and wanted to give up. I thought coding was not for me, but I reminded myself that every programmer experiences struggles while learning.

I tried to stay calm and checked the code carefully. I searched for solutions on the internet and slowly fixed every error. Finally, the program worked perfectly.

That experience taught me that coding is not only about writing commands, but also about patience, persistence, and never giving up easily.
